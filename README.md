# Sayso

Portable voice-first dictation with AI rewriting for locked-down Windows. Hold a hotkey, talk, release, and
polished text appears in whatever app has focus. No admin rights, no install, no telemetry.

Status: architecture and core reference code. See `docs/ARCHITECTURE.md` and `docs/IMPLEMENTATION_PLAN.md`
(the build spec). The full README is milestone M6 of the plan.
