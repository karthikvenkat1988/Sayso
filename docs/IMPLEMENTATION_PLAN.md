# Sayso implementation plan

This is the build spec for the coding thread. Read `docs/ARCHITECTURE.md` first for the diagrams. Work through
the milestones in order; each one ends with green tests and a commit. Where this plan and the existing code
disagree, the existing code in the "done" files wins unless this plan says to change it.

Product in one line: hold a hotkey, talk, release, and polished text appears in the focused Windows app, on a
locked-down corporate laptop, with no admin rights and no install.

## 0. Ground rules

- Python 3.11+ (3.12 for builds). Package lives in `src/sayso`. Run from source with `python -m sayso`.
- Layering is strict: `core`, `stt`, `llm` must not import Qt, `ctypes.windll`, or anything under `winsys`/`ui`.
  `winsys` is the only place that touches Win32. `ui` is the only place that imports PySide6. CI checks this
  (see `tests/test_layering.py`).
- Every Windows-only module must import cleanly on Linux: guard Win32 access behind `sys.platform == "win32"`
  inside functions, or raise `PlatformUnavailable` at construction time. Tests run on Ubuntu and Windows.
- Use `ctypes` for Win32. Do not add `pywin32` or `keyboard`/`pynput`: they complicate freezing and some EDR
  tools flag them. `comtypes` is allowed only for UI Automation and must be optional.
- Never log transcripts or inserted text. Log stages, timings, method names and error types.
- No network calls except the configured STT/AI endpoints. No telemetry, no update checks.
- Style: ruff (config in `pyproject.toml`), type hints everywhere, docstrings only where behaviour is not
  obvious. Match the existing modules' comment density.
- Branding is original: name "Sayso", palette Ink `#14162B`, Ink-2 `#1E2140`, Ember `#FF7A59`, Tide `#5CC8B8`,
  Mist `#E9EBF5`, Danger `#FF5C7A`, Success `#5CD68A`. Do not imitate any other product's visuals or copy.

## 5. File-by-file specs (to build)

### 5.1 `src/sayso/__main__.py`

```python
def main(argv: list[str] | None = None) -> int
```
argparse flags: `--portable` (sets `SAYSO_PORTABLE=1` before paths resolve), `--home PATH` (`SAYSO_HOME`),
`--offline` (forces `privacy.offline_only` for this run), `--diagnose` (prints capability report JSON from
`core.capabilities.probe()` and exits 0), `--transcribe FILE.wav` (runs STT chain + AI chain on a file, prints
text; used in CI smoke tests and by IT), `--mode MODE`, `--version`. Default: `return app.run(args)`.
When frozen with `console=False`, `--diagnose` writes to `diagnose.json` next to the data dir as well.

### 5.2 `src/sayso/app.py`

```python
def run(args: argparse.Namespace) -> int
```
1. `paths = resolve_paths().ensure()`; `setup_logging(paths.log_file)`.
2. `winsys.single_instance.acquire("Local\\Sayso")`; if already running, signal the running instance to show
   settings (named event `Local\\Sayso.Show`) and exit 0.
3. Create `QApplication` with `setQuitOnLastWindowClosed(False)`, high-DPI policy `PassThrough`,
   `ui.theme.apply(app)`.
4. `loaded = load_settings(paths.settings_file, paths.policy_file)`; apply `--offline`.
5. Build `CredentialStore(paths)`, `History`, `Controller(app, paths, loaded, creds, history)`; `controller.start()`.
6. `return app.exec()`; on exit `controller.shutdown()`.
Wrap everything in a top-level handler that logs the exception and shows a `QMessageBox` with the log path.

### 5.4 `src/sayso/audio/vad.py`

Pure numpy, no I/O.
```python
class EnergyVad:
    def __init__(self, sample_rate: int = 16000, frame_ms: int = 30, threshold_db: float = -42.0,
                 start_frames: int = 2, end_ms: int = 700, pre_roll_ms: int = 300)
    def process(self, frame: np.ndarray) -> list[VadEvent]   # VadEvent = SPEECH_START | SPEECH_END(segment)
    def reset(self) -> None
def frame_db(frame: np.ndarray) -> float
```
Adaptive noise floor: track the 10th percentile of the last 3 s of frame energies; speech = energy above
`max(threshold_db, floor + 10 dB)` for `start_frames` consecutive frames. Keep `pre_roll_ms` of audio so the
first syllable is not clipped. Segment = pre-roll + speech + `end_ms` hangover. Detection latency must be
≤ 2 frames (60 ms), meeting the < 100 ms target. Optional: if `webrtcvad` is importable use it as the
speech/no-speech decision per frame (same interface).

### 5.5 `src/sayso/audio/capture.py`

```python
class AudioCapture(QObject-free plain class):
    def __init__(self, sample_rate=16000, device: str | None = None, block_ms: int = 30)
    on_level: Callable[[float], None] | None        # 0..1 peak, every block
    on_frame: Callable[[np.ndarray], None] | None   # always-listening VAD feed
    def open(self) -> None          # opens the InputStream once (kept open only while recording unless always-listening)
    def start(self) -> None         # begin collecting into buffer
    def stop(self) -> AudioClip     # returns float32 mono clip, trims to audio.max_seconds
    def cancel(self) -> None
    def close(self) -> None
    @staticmethod
    def devices() -> list[tuple[str, str]]   # (id, display name) of input devices
class MicrophoneUnavailable(Exception)
```
Use `sounddevice.InputStream(samplerate, channels=1, dtype="float32", blocksize=sr*block_ms//1000,
latency="low")`. If the device rejects 16 kHz, open at its default rate and resample with
`np.interp` (linear is fine for speech). Callback: copy into a preallocated ring (`max_seconds` capacity),
compute peak → `on_level`, pass frame → `on_frame`. No allocation per callback beyond the copy. Raise
`MicrophoneUnavailable(detail)` with a human-readable hint (privacy setting path) when PortAudio fails.
Start latency target: first frame captured within 100 ms of `start()`; to achieve this, open the stream on
hotkey *key-down* and keep a 300 ms pre-roll while the stream warms.

### 5.7 `src/sayso/winsys/hotkey_logic.py` (pure, fully unit-tested)

```python
@dataclass(frozen=True)
class Chord:            # parsed from "ctrl+alt+space", "capslock*2", "f9", "rctrl"
    keys: frozenset[int]          # VK codes; "ctrl"/"alt"/"shift"/"win" match left OR right
    double_tap: bool
    @classmethod
    def parse(cls, spec: str) -> Chord     # raises ValueError with a readable message

class Action(Enum): START_PTT, START_TOGGLE, STOP, CANCEL, TOGGLE_ALWAYS, COMMAND_ON, REINJECT_CAPSLOCK
@dataclass
class Decision:
    actions: list[Action]
    swallow: bool                 # True → hook returns 1 so the app never sees the key

class HotkeyStateMachine:
    def __init__(self, ptt: Chord | None, toggle: Chord | None, always: Chord | None,
                 command_modifier: int | None, cancel_vk: int, double_tap_ms: int)
    def on_key(self, vk: int, down: bool, t_ms: int, injected: bool = False) -> Decision
    @property
    def recording(self) -> bool
    def notify_processing(self, busy: bool) -> None   # Esc cancels processing too
```
Rules:
- Ignore events with `injected=True` (our own `SAYSO_TAG`) and auto-repeat downs (key already down).
- PTT: when all chord keys are down → `START_PTT` (+`COMMAND_ON` if the modifier is down); swallow the
  non-modifier trigger key (e.g. Space) on down, repeats and up so no spaces are typed. Releasing any chord key
  → `STOP`.
- Modifier-only chords are allowed (e.g. `rctrl`), never swallowed.
- Toggle chord press while idle → `START_TOGGLE`; press while toggle-recording → `STOP`.
- Double tap (`capslock*2`): swallow every CapsLock down/up while the binding is active. Second down within
  `double_tap_ms` of the first → toggle action. If the window expires after a single tap, emit
  `REINJECT_CAPSLOCK` so Caps Lock still works for the user (the service sends a tagged CapsLock press).
- Command modifier pressed while recording → `COMMAND_ON`.
- Cancel key while recording or processing → `CANCEL` (do not swallow Esc).
- Always-listening chord → `TOGGLE_ALWAYS` (ignored if `activation.always_listening_allowed` is false; the
  service passes `None` for that chord).
- Timer expiry for double-tap is evaluated on the next event or via `tick(t_ms)`; expose
  `def tick(self, t_ms) -> Decision`.

### 5.8 `src/sayso/winsys/hotkeys.py`

```python
class HotkeyService(QObject):
    started = Signal(str, bool)       # ("ptt"|"toggle", command)
    stopped = Signal()
    cancelled = Signal()
    command_engaged = Signal()
    always_listening_toggled = Signal()
    backend_changed = Signal(str)     # "hook" | "registerhotkey" | "none"
    def __init__(self, settings: HotkeySettings, activation: ActivationSettings)
    def start(self) -> None
    def reconfigure(self, settings, activation) -> None
    def stop(self) -> None
    def set_processing(self, busy: bool) -> None
```
Runs a dedicated `threading.Thread(daemon=True)` that installs `WH_KEYBOARD_LL` with
`GetModuleHandleW(None)` and pumps `GetMessageW`. The C callback must keep a reference to the
`HOOKPROC` object. Callback: build event → `state_machine.on_key` → emit Qt signals (thread-safe, queued) →
return 1 if swallow else `CallNextHookEx`. Keep the callback under 1 ms (Windows silently removes slow hooks
after `LowLevelHooksTimeout`; re-install if `GetLastError` indicates removal: check every 5 s with a
`SetTimer` on the hook thread that verifies the last callback was within the expected window and re-hooks).
When a chord with Space is swallowed and Alt is in the chord, send a tagged dummy key VK `0xE8`
down/up before releasing so Alt release does not open the app menu.
Fallback: if `SetWindowsHookExW` fails (EDR policy), use `RegisterHotKey` on the same thread for the toggle
chord and PTT chord (both behave as toggle: press start, press stop) and emit `backend_changed("registerhotkey")`;
`capslock*2` is not possible there, so map it to `ctrl+alt+space` toggle and log it. Stop: `PostThreadMessageW(WM_QUIT)`.

### 5.9 `src/sayso/winsys/context.py`

```python
def foreground_hwnd() -> int
def capture(hwnd: int, *, want_selection: bool = True, timeout_s: float = 0.3) -> FocusContext
def is_process_elevated(pid: int) -> bool
```
Basic info (always, < 2 ms): title (`GetWindowTextW`), process name via `QueryFullProcessImageNameW` stem,
focused control via `GetGUIThreadInfo(threadId).hwndFocus` and its class name.
UIA (optional, `comtypes`): run in a worker thread that has called `CoInitializeEx(MTA)` once (keep one
long-lived UIA thread with a queue; creating `CUIAutomation` per call is slow). Get `GetFocusedElement()`;
`CurrentIsPassword` → `is_password`; if it supports TextPattern: selection text (max 8000 chars) and text
before caret (range from document start moved to selection start, last 1200 chars). Results not ready within
`timeout_s` are dropped and the basic context is returned. Classic edit fallback for text-before-caret when
UIA is missing: `WM_GETTEXTLENGTH`/`WM_GETTEXT` + `EM_GETSEL` via `SendMessageTimeoutW` (200 ms,
`SMTO_ABORTIFHUNG`) for classes `Edit`, `RichEdit20W`, `RICHEDIT50W`. Set `comtypes.client.gen_dir` to
`paths.data_dir / "comtypes_gen"` before importing generated modules (frozen builds have a read-only bundle).
`is_elevated_target`: compare target process elevation with ours; UIPI blocks our input into elevated windows,
so the controller shows "Can't type into an admin window; text copied to clipboard" and uses clipboard-only.

### 5.10 `src/sayso/winsys/clipboard.py`

```python
class ClipboardBusy(Exception)
class ClipboardSnapshot:
    @classmethod
    def take(cls) -> ClipboardSnapshot        # copies all HGLOBAL-backed formats (skip GDI/metafile/owner-display)
    def restore(self) -> None
```

copy something new meanwhile).

### 5.11 `src/sayso/winsys/injection_policy.py` (pure, unit-tested)

```python
METHODS = ("paste", "accessibility", "keyboard", "clipboard")
@dataclass(frozen=True)
class TargetInfo:
    process: str; control_class: str; text_len: int; clipboard_ok: bool; uia_ok: bool
    elevated_target: bool; remote_session: bool; replace_selection: bool
def choose_methods(target: TargetInfo, configured: str, overrides: dict[str, str]) -> list[str]
```
Returns an ordered list to try. Rules, first match wins:
1. `elevated_target` → `["clipboard"]`.
2. `overrides[process]` → that method, then `"clipboard"`.
3. `configured != "auto"` → `[configured, ...fallbacks in default order..., "clipboard"]`.
4. Remote/virtual app clients (`mstsc`, `wfica32`, `CDViewer`, `vmconnect`, `vmware-view`, `msrdc`) → keyboard
   first (local clipboard often is not redirected), then paste, then clipboard.
5. Terminals (`WindowsTerminal`, `conhost`, `powershell`, `pwsh`, `cmd`, `mintty`, `putty`) → paste (Ctrl+V
   works in Windows Terminal), then keyboard.
6. Classic edit classes (`Edit`, `RichEdit*`, `RICHEDIT50W`) and not `clipboard_ok` → accessibility first.
7. Default: `paste` if `clipboard_ok`, then `accessibility` if `uia_ok` or classic edit, then `keyboard`
   (skip keyboard when `text_len > 4000`; put it after clipboard), then `clipboard`.
Always ends with `"clipboard"` (cannot fail; the toast tells the user to press Ctrl+V).

### 5.12 `src/sayso/winsys/injection.py`

```python
@dataclass
class InsertReport: method: str; ok: bool; ms: int; tried: list[tuple[str, str]]; needs_manual_paste: bool
class InjectionMethod(ABC):
    name: str
    def insert(self, text: str, ctx: FocusContext, replace_selection: bool) -> None   # raise InjectionFailed
class PasteMethod, AccessibilityMethod, KeyboardMethod, ClipboardOnlyMethod
class Injector:
    def __init__(self, settings: InjectionSettings)
    def insert(self, text: str, ctx: FocusContext, *, replace_selection: bool = False) -> InsertReport
    def copy_selection(self) -> str | None
```
Shared prep before any method: wait until physical modifiers (Ctrl/Shift/Alt/Win via `GetAsyncKeyState`) are
up, max 600 ms, so Ctrl+V is not sent as Ctrl+Shift+V; if foreground changed since key-down, call
`SetForegroundWindow(ctx.hwnd)` (allowed because we just received input). Normalise newlines to `\r\n` for
paste/accessibility, `\n` → VK_RETURN for keyboard.
- **PasteMethod** (method 1, "simulated paste"): snapshot clipboard, `set_text`, `SendInput` Ctrl down, V
  down, V up, Ctrl up (tagged), sleep `paste_settle_ms`, restore snapshot if `restore_clipboard`. Target
  insertion < 100 ms excluding the settle delay.
- **ClipboardOnlyMethod** (method 2, "clipboard replacement"): `set_text` and leave it; report
  `needs_manual_paste=True`; overlay shows "Copied. Press Ctrl+V". Used for Citrix clipboard-only setups,
  elevated targets, and as the final fallback.
- **AccessibilityMethod** (method 3): classic edits → `SendMessageTimeoutW(hwndFocus, EM_REPLACESEL, 1, text)`;
  otherwise UIA `ValuePattern`: only when the field is empty, or `replace_selection` and the selection equals
  the whole value (setting a value replaces everything, so never use it mid-text); verify by re-reading value.
- **KeyboardMethod** (method 4): `SendInput` with `KEYEVENTF_UNICODE` in chunks of `keyboard_chunk` chars
  (pairs of down/up, surrogate pairs for emoji), 5 ms between chunks; newline → Enter; tab → Tab.
`replace_selection` for paste/keyboard needs nothing extra (typing replaces the selection).
`copy_selection`: snapshot, clear, tagged Ctrl+C, poll sequence number up to 250 ms, read text, restore.

### 5.13 `src/sayso/winsys/credentials.py`

```python
class CredentialStore:
    def __init__(self, paths: AppPaths, *, prefer: str = "auto")   # auto | credman | dpapi | memory
    def get(self, ref: str) -> str | None
    def set(self, ref: str, secret: str | None) -> None             # None/"" deletes
    def backend(self) -> str
```
Lookup order: environment variable `SAYSO_SECRET_<REF upper, dots→underscores>` (IT can inject), then
backend. Backends: **credman** = Windows Credential Manager generic credential `Sayso/<ref>`,
`CRED_PERSIST_LOCAL_MACHINE` (per user, not roamed); **dpapi** = JSON dict encrypted with `CryptProtectData`
(user scope, entropy `b"Sayso.v1"`) at `paths.secrets_file`, atomic write; **memory** = dict (non-Windows,
tests). `auto` → dpapi in portable mode (keeps the stick self-contained), credman otherwise, falling back to
dpapi if CredWrite fails (some policies disable Credential Manager), then memory with a warning. Never log
values. Settings UI shows only "Saved" / "Not set".

### 5.21 `src/sayso/ui/controller.py`

```python
class Controller(QObject):
    dictated = Signal(object)    # DictationResult
    def __init__(self, app, paths, loaded: LoadedSettings, creds: CredentialStore, history: History)
    def start(self) -> None
    def shutdown(self) -> None
    def start_dictation(self, kind: str = "toggle", command: bool = False) -> None   # used by tray too
    def stop_dictation(self) -> None
    def cancel(self) -> None
    def reload_settings(self) -> None
```
Owns: `HotkeyService`, `AudioCapture`, `EnergyVad` (always-listening), `SttChain`, `ProviderChain`,
`Pipeline`, `Injector`, `Overlay`, `Tray`, windows, a single-worker `ThreadPoolExecutor`, `LocalMetrics`.
Flow per dictation (see sequence diagram):
1. On start: ignore if paused or busy. Record `target_hwnd = foreground_hwnd()`; submit
   `context.capture(target_hwnd)` to a separate small executor; `audio.start()`; overlay RECORDING/COMMAND;
   play start sound (async `QSoundEffect`, preloaded).
2. On stop: `clip = audio.stop()`; overlay PROCESSING; `busy=True`; `hotkeys.set_processing(True)`; submit
   worker job.
3. Worker job: wait for context (≤ 300 ms); if command and no selection → `injector.copy_selection()`; if
   `is_elevated_target` force clipboard; `pipeline.run(... on_stage, on_transcript, on_delta)` with callbacks
   that emit Qt signals to update the overlay; `text = join_with_context(...)`; `report = injector.insert(...)`;
   history add; metrics add.
4. Back on UI thread: SUCCESS with latency (`stt+llm+insert`), or the clipboard hint, or ERROR with a specific
   message (map `NoEngineAvailable`, `MicrophoneUnavailable`, `ClipboardBusy` etc. to texts from §6).
5. Cancel: cancels audio; sets a `threading.Event` checked between pipeline stages; the result is discarded.
Always-listening: `audio.on_frame → vad.process`; each SPEECH_END segment is queued to the worker using the
context captured at segment start; overlay ALWAYS_LISTENING; any PTT press takes priority and pauses VAD.
Warm-up at start (background): `stt.warm_up()`, `llm` health checks, `capabilities.probe(quick=True)` → tray
tooltip and first-run notice. First run (no settings file): open Settings on the AI page with a short welcome
banner and the shortcut cheat-sheet.

## 11. Performance budget

| Stage | Target | How |
|---|---|---|
| Voice detection | < 100 ms | stream opened on key-down, 30 ms frames, 2-frame VAD |
| Transcription (5 s audio) | < 1 s | faster-whisper base.en int8, beam 1, model loaded at start-up, `vad_filter` on |
| Rewrite | < 2 s | Claude effort `low`, cached system prompt, streaming; 6 s timeout then next provider; ≤ 4-word utterances in `rewrite_text` skip AI (use offline rules) |
| Insertion | < 100 ms | paste path; settle delay happens after the paste is sent |
| Memory | < 500 MB | base.en int8 ≈ 150 MB; Qt Essentials only; one model loaded at a time |

`OfflineRewriter.apply` and skip the chain.
