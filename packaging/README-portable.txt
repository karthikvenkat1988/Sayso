Sayso portable
==============

1. Unzip this folder anywhere: Documents, a network share or a USB stick. No admin rights needed.
2. Double-click Sayso.exe. A Sayso icon appears near the clock (click the ^ if it is hidden).
3. Hold Ctrl+Alt+Space, talk, let go. Your words appear where you were typing.

Everything Sayso saves (settings, history, models, logs) stays in the "data" folder next to Sayso.exe.
Delete the folder and Sayso is gone. The empty file named "portable" is what turns this mode on.

If Sayso.exe is blocked on your computer, see docs/ENTERPRISE.md or ask IT for the "sayso.pyz" build.
Sayso sends nothing about how you use it. It only contacts the AI service you set up in Settings.
